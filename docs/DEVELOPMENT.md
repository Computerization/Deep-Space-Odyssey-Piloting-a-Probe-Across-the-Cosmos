# Development and verification

Cosmos runs directly from its editable source. Start it with `npm start` or `python3 server.py`; open `http://127.0.0.1:4173`. `npm test` runs the dependency-free unit suite. The game needs no package installation or external assets.

The [architecture](ARCHITECTURE.md) identifies each system's owner. The [repair list](REPAIR-STATUS.md) records current findings. Full revision measurements remain in `docs/revisions/experience-audit-v13.md` in the development workspace. Historical evidence describes its recorded source, not every later release.

## Atmospheric and cloud references

A trial merging view/light segment integration was rejected after a paired GPU comparison increased the day-scene cost by about 15%; keep the specialized hot paths unless measured evidence supports changing them. The comparison record stays in the development ledger.

`scientific-experience.mjs` checks the current Earth dimensions through the actual production vertex shader at equatorial/polar viewpoints and near/far scaled-space distances. Independent kilometre integrals check twenty optical-table nodes and fifty bounded production transmission rays per engine. The same runner retains rate-independent clocks, arrivals, free flight and saved observation checks.

`earth-transmission.mjs` retains frozen prior shaders only as development fixtures. Its historical comparisons use the old 6,371 km dimensional convention; use the scientific-experience runner for current-axis verification until those fixtures and independent references are explicitly normalized to one scale. It checks RGB background attenuation, isolated incoming sunlight, merged/split cloud composition, multisampling, reduced cloud resolution, capture and chase routes. Independent 8,192-step integration checks full and bounded atmospheric rays, including interior origins and tangent crossings. Other-world image comparisons catch shared-surface regressions.

Ground-shadow checks cover seven day/terminator/near/glint/polar/seam views. Isolated surfaces use 128 segments as a reference and 256 for convergence; full frames retain clouds and atmosphere. Twenty-four uniform-cloud cases read production shadow transmission before shading/display conversion and compare it with independent density integration.

`cloud-light.mjs` compares twelve views and moving cameras against 64/128-segment sunlight references, isolating the sky contribution for that historical comparison. The complete illuminated shader must preserve cloud coverage and add finite nonnegative radiance. Forty-five altitude/Sun-angle cases compare the shipping sky function with independent 8,192-elevation integration, including quadrature-node limits and zero illumination below the horizon. Nine independent altitude/Sun-angle cases check the complete production light path. `cloud-map.mjs` compares 4,096 seeded paths at four positions each against exact spherical mapping, including polar, seam and long-path fallbacks. Numerical convergence measures this reconstruction's accuracy, not photographic equivalence.
